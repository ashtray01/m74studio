# Проверки первой версии

## Go

`go test ./...`, `go vet ./...` и сборка Windows amd64.

Тесты проверяют:

- контрольные значения реального пакета;
- знаковые границы обратного кода;
- сохранение пропусков в коротком/невалидном ответе;
- восстановление полного ответа после повреждённого префикса;
- отсутствие дублирования `Fixed toLineMF`;
- переход даты через полночь и отклонение нарушенного порядка времени;
- отказ для неподдерживаемого профиля;
- экспорт выбранных кадров, кириллицу, десятичный разделитель и пустые поля;
- полный предоставленный лог: 3540 кадров, ожидаемые количества дефектов, калибровку I464SG04.

## Интерфейс

`scripts/ui-smoke.cjs` запускает фоновый Chrome с теми же встроенными HTML/CSS/JS и JSON, полученным реальным Go-декодером. Проверены графики, курсор, выделение, масштабирование, таблица и её страницы, события качества, поиск, наборы, фильтр флагов, аргументы экспорта CSV/TXT и воспроизведение. Проверяются отсутствие ошибок JavaScript и размеры 1540×940 / 1180×701.

В собранном M74Studio.exe на установленном WebView2 отдельно проверены открытие исходного лога через системный диалог и сохранение полных CSV/TXT через кнопки интерфейса. SHA-256 обоих сохранённых файлов совпадает с экспортом Go через командную строку. Фоновый браузерный тест не подменяет эту проверку. Снимки интерфейса и временные результаты находятся в `test-output`; они не нужны пользователю для запуска.

Запуск без необязательного `demo-2026-10-01.log` проверен в отдельной папке: EXE открывает пустое рабочее место без аварийного завершения. Браузерный тест также проверяет пустое состояние, недоступность экспорта до загрузки и успешное открытие лога кнопкой.

Автотест интерфейса требует Node.js, установленный Chrome и `playwright-core` (`npm install --no-save playwright-core` из `m74studio`). Он использует локальную контрольную запись, преобразованную командой `M74Studio.exe -input demo-2026-10-01.log -json test-output/session.json`. Запускать `node scripts/ui-smoke.cjs` из `m74studio`. Это инструменты разработки, не зависимости приложения. Полная запись не публикуется в Git, поэтому этот сценарий не входит в CI.

## Переносимая проверка сборки

`scripts/check-cli.ps1` запускает собранный EXE на одном встроенном контрольном пакете и проверяет CSV, TXT и JSON. Этот сценарий выполняется в GitHub Actions без локальных файлов. `scripts/package.ps1` создаёт ZIP только из EXE, документации и лицензий, затем записывает SHA-256. Личный лог и отчёты не попадают в пакет.

## Скриншоты

`node scripts/screenshots.cjs test-output/session.json` пересоздаёт четыре изображения в `docs/images`. Используется тот же интерфейс; имя записи заменяется на демонстрационное, VIN скрывается. Баннер — отдельный SVG в той же папке.

## Регрессии версии 1.1

`TestSecondPacketAndMissingResponses` проверяет переход на пакет `220002`, общие параметры, отсутствие подстановки полей другой схемы, короткие/неверные ответы и запрос без ответа в конце файла. Выполняется в CI без личных записей. `TestMixedRecording` дополнительно проверяет локальный лог из `temp`; при его отсутствии тест пропускается.

Для проверки интерфейса подготовить `test-output/session-mixed.json` командой `M74Studio.exe -input <смешанный-лог> -json test-output/session-mixed.json`, затем выполнить `node scripts/ui-mixed-smoke.cjs` из каталога `m74studio` (Chrome и playwright-core). Сценарий рассчитан на локальную запись из 2466 кадров: проверяет добавление 12 графиков, вертикальную прокрутку без масштабирования, Shift + колесо, масштабирование на нижней панели, перетаскивание окна включая границы и отмену, добавление/удаление/перестановку карточек, тёмный фон options, таблицу, экспорт и компактный размер окна. Локальный сценарий не входит в CI.

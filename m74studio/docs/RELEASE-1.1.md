# M74 Studio 1.1

- Исправлена потеря продолжения записи при переключении с `220001` на `220002`. Все запросы сохраняются на временной шкале, включая отсутствующие ответы. Для `220002` поддерживаются общие параметры p001–p010; специфические поля остаются в HEX.
- Объединены верхние панели, убраны повторяющиеся служебные подписи.
- Карточки показаний можно добавлять, удалять и переставлять мышью или клавиатурой.
- Убран лимит в шесть графиков; длинный список прокручивается.
- Колесо над графиками прокручивает список вертикально. Shift + колесо сдвигает время. Масштабирование и его кнопки перенесены на панель воспроизведения.
- Нижняя шкала перемещает видимую область без изменения выделения для экспорта.
- Исправлен светлый фон выпадающих списков параметров.

Проверки: Go test/vet, Windows-сборка, экспорт EXE в CSV/TXT/JSON и браузерный сценарий `scripts/ui-mixed-smoke.cjs`. Локальная смешанная запись: 2466 кадров вместо прежних 222. Личные записи не входят в репозиторий или архив релиза.

Анализ логов OpenDiag

Автономное Windows-приложение на Go. Поддерживает основной пакет параметров Ителма М74CAN.

Пакет 220001: 75 описаний параметров. Пакет 220002: общие параметры двигателя; остальные поля доступны в HEX. Доступность зависит от длины ответа. М74 без CAN и М74CAN MAP используют другие профили.

Все вычисления выполняются на компьютере. В экспорте нет интерполяции: пропуски остаются пропусками. Приложение показывает параметры записи; автоматическое заключение о неисправностях не формируется.

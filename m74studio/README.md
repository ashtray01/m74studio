# M74 Studio

Автономное Windows-приложение для расшифровки логов **OpenDiag Mobile / Ителма М74CAN**. Обработка и экспорт написаны на Go, интерфейс работает внутри отдельного окна WebView2. Интернет для работы не требуется.

## Запуск

Откройте **M74Studio.exe**. Нужны Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Go, Python и Node.js для запуска нового приложения не нужны.

Необязательный тестовый файл `demo-2026-10-01.log` автоматически открывается, если находится рядом с EXE. Без него приложение открывает пустое рабочее место с кнопкой выбора лога. Другой файл можно выбрать кнопкой **Открыть лог**, перетащить в окно или передать аргументом командной строки.

В исходной локальной рабочей папке готовая расшифровка находится в **exports**: полная таблица CSV и текстовый отчёт TXT. Личный лог и эти экспорты исключены из Git и релизного ZIP.

## Работа

- Слева — поиск и выбор сигналов. Можно добавлять все доступные сигналы; список графиков прокручивается. Флаги находятся на отдельной вкладке списка.
- В заголовке каждого графика можно заменить сигнал. Готовые наборы: двигатель, смесь, воздух/впрыск, электрика/флаги.
- Курсор и масштаб времени общие. Наведение показывает значения кадра; колесо над графиками прокручивает список, над нижней панелью меняет масштаб; Shift + колесо сдвигает область просмотра.
- Протяните мышью по графику для выделения участка. **Приблизить участок** увеличивает его; Двойной щелчок по нижней шкале показывает всю запись.
- **Таблица** показывает выбранные сигналы, **События** — пропуски, повреждённые ответы и изменения нескольких основных флагов. Щелчок по событию переводит курсор к нужному кадру.
- Справа — паспорт ЭБУ, качество данных, статистика активного сигнала и исходный HEX кадра. При выделении статистика рассчитывается только по участку.
- Кнопка воспроизведения последовательно перемещает курсор с учётом реальных временных интервалов. Скорости: 1×, 4×, 16×.

Горячие клавиши: `Ctrl+O` — открыть; `Ctrl+E` — CSV; `←/→` — кадр; `Shift+←/→` — 10 кадров; `Home/End` — начало/конец; `Пробел` — воспроизведение; `/` — поиск; `Esc` — снять выделение.

## Экспорт

Выберите всю запись, выделенный участок или видимую область; затем все присутствующие параметры либо сигналы на графиках.

**CSV:** UTF-8 с BOM. По умолчанию `;` между колонками и десятичная запятая для русского Excel. Если снять настройку Excel — разделитель `,`, десятичная точка. Есть номер кадра, время, относительное время, качество, строка исходного лога и значения с названиями и единицами.

**TXT:** UTF-8, паспорт ЭБУ, словарь параметров, качество интервала, min/max/среднее, события и полная таблица TSV. Для нейросети достаточно передать этот файл: обозначения и ограничения включены в сам отчёт.

Пустая ячейка CSV и `NA` в TXT означают **нет данных**, а не нулевое показание. Полные данные экспортируются независимо от уплотнения графика при отдалении. Среднее — арифметическое по имеющимся отсчётам, без взвешивания по времени. Часовой пояс в логе отсутствует; время сохраняется как локальное, дата берётся из имени файла, переход через полночь учитывается.

## Что поддерживается

Основной пакет `22 00 01 → 62 00 01` профиля М74CAN: **75 описаний**, из них 34 числовых/служебных значения и 41 флаг. В предоставленном логе присутствуют **73 параметра**: два последних флага относятся к необязательному 60-му байту, которого в этой записи нет. Контрольная сумма ПЗУ отображается как HEX и входит в полный экспорт; график для неё не строится.

Паспорт извлекается из идентификационных ответов `22 00 90…A3`. Пакеты служебного обмена не превращаются в измерения.

**Границы первой версии:** М74 без CAN, М74CAN MAP и другие ЭБУ не поддерживаются. Сравнения логов нет. Дополнительные группы АЦП, детонации, пропусков воспламенения и расшифровка кодов DTC не реализованы. Параметр «Количество ошибок» доступен, но сам по себе не указывает причины. Приложение читает файлы и не подключается к автомобилю.

Формулы и единицы измерения задаются профилем М74CAN. Отрицательные величины декодируются в обратном коде. Проверка на контрольных пакетах не заменяет проверку всех режимов работы ЭБУ. Подробности: [docs/DECODING.md](docs/DECODING.md).

## Результат проверки исходного лога

3540 запросов параметров, 08:21:01.261–08:37:03.574, длительность 962.313 с, медианный интервал 256 мс:

| Качество | Кадров |
|---|---:|
| Полный обязательный пакет | 3502 |
| Неполный ответ | 31 |
| Повреждённый/неподходящий ответ | 6 |
| Полный ответ после повреждённого префикса | 1 |

Дублирующие строки `Fixed toLineMF` не считаются кадрами. Неполный ответ расшифровывается только до последнего целого параметра. Значения не переносятся из соседних кадров. На графиках есть разрывы при отсутствии значения и при длинных паузах.

## Сборка

Нужны Go 1.26+, GCC/MinGW-w64 (например, w64devkit) и `windres` для значка и манифеста. Путь `bin` компилятора должен быть в `PATH`.

Закройте приложение, затем из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт использует локальный кэш `.cache/go`, запускает тесты, `go vet` и создаёт `M74Studio.exe`. Изменение политики PowerShell применяется только к этому запуску. Первая сборка скачивает Go-зависимость, последующие используют кэш.

Без интерфейса:

```powershell
.\M74Studio.exe -input "demo-2026-10-01.log" -export "result.csv" -format csv
.\M74Studio.exe -input "demo-2026-10-01.log" -export "segment.txt" -format txt -from 100 -to 250
```

`from/to` — номера кадров начиная с 1, границы включены. `-to 0` означает до конца. `-excel=false` включает CSV с точкой и запятой-разделителем. `-json result.json` сохраняет полную декодированную сессию для интеграций.

## Структура

- `internal/decoder` — парсер, формулы, каталог М74CAN, события, экспорт и тесты. Добавление профилей следует начинать здесь, с отдельной проверкой идентификации и схемы пакета.
- `ui` — интерфейс и Canvas-графики, встроенные в EXE.
- `main.go`, `native_windows.go` — окно, нативные диалоги и связь с Go.
- `scripts` — проверка CLI, упаковка релиза и инструменты для скриншотов/проверки интерфейса.
- `docs` — происхождение формул и сведения о проверках.

GitHub Actions собирает Windows x64 и публикует релизы по тегам: [инструкция](docs/GITHUB.md). Сторонние компоненты перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).

Карточки показаний сверху: «+» открывает выбор параметра, «−» убирает карточку. Перетащите карточку за «⋮⋮», чтобы поменять порядок; доступны также стрелки ←/→ при фокусе на ручке. Shift + колесо сдвигает увеличенные графики влево и вправо.

Смешанные логи `220001` / `220002` читаются целиком. У `220002` расшифрованы общие параметры p001–p010; остальные поля видны в исходном HEX. Отсутствующие ответы сохраняют место на временной шкале.
